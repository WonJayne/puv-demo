This repository accompanies the public transport lectures at **ETH Zurich**. It encompasses a line planning problem 

## Project Structure

- `src/openbus_light/` – library code
- `line_planning.py` – line planning script
- `data/` – input data used in the exercises
- `results/` – output folder created when running the experiments
